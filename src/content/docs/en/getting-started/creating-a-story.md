A **story** is your whole work. It has one or more **chapters**, and readers buy and read the chapters. All chapters of a story share the title, cover, genre, tags, age recommendation, characters, variables and global events.

## Create New Epos

Open **My Stories** and choose **Create Story**. In the **Create New Epos** dialog you fill in:

1. **Story Title** (required, 200 characters at most). It is shown on the cover card in the library.
2. **Description** (optional, formatted text, 1000 characters at most). Two or three sentences are enough to start.

Until you enter a title, **Create Epos** is disabled and the text next to it reads "Add a title to create the story." You can change everything from the dialog later on the story's detail page or in **Global Settings** in the editor header (the cog next to the book icon). You set the genre and tags later, at the latest in the **Metadata** step when you publish.

![the Create New Epos dialog with an empty title and description. On the right, a What happens next panel: a private draft is created, the story editor opens, and you can add the cover any time before publishing](/screens/en/getting-started/create-story-dialog.png)

The **What happens next** panel on the right sums up what happens next: a private draft is created that only you can see until you publish a chapter, the story editor opens, and you can add the cover any time before publishing.

This dialog doesn't set the cover. Use the **Thumbnail** button on the story's detail page. You can't publish a chapter until the story has a cover. See [Cover image](/en/media/cover-image/).

A new story starts with one empty chapter, **Chapter 1**, and TalePort opens the editor right away.

## Locked content

Publishing a chapter locks its graph. Some story-wide items get locked too. See [Published content restrictions](/en/publishing/published-content-restrictions/).

- **Characters:** a character is locked once it speaks a line in a live chapter. A character in a node without a line stays editable.
- **Global events:** all of them are locked as soon as any chapter is live, even events that chapter doesn't fire. The variable each event targets is locked with it.
- **Variables:** a variable is locked when a live chapter changes it in an event or checks it in a requirement. The stat variables of a locked character are locked too.
